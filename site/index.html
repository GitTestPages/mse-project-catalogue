Before you choose a project

Most projects can be done as group work

Most of the projects in this catalogue can be carried out by a group of students, not only individually. If you would like to work together with other students, discuss the possibilities with the supervisors of the project before you choose it. You can contact them from each project's page.

Not ready for a project yet?

Take a project course first, to learn the prerequisite knowledge and techniques you need. Contact Karen Pantleon (kapa@dtu.dk).
